# anabutir-moodle

Aplikasi analisis butir soal ujian LMS Moodle berbasis web (client-side).

## Fitur
- Analisis otomatis tingkat kesukaran (P) dan daya pembeda (D)
- Evaluasi efektivitas distraktor / pengecoh pilihan ganda
- Analisis bobot kombinasi soal pilihan ganda & esai
- Ekspor laporan cetak format PDF dan Excel (.xlsx)
- Form metadata ujian di halaman awal (Mapel, Kelas/Fase, Kota, Guru, Kepala Sekolah)

## Panduan Penggunaan
1. Unduh berkas statistik lengkap kuis dari LMS Moodle (.csv atau .xlsx).
2. Isi identitas ujian pada formulir di halaman utama.
3. Unggah berkas untuk melihat hasil analisis dan cetak laporan.
